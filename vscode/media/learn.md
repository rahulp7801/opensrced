# Learn an issue

Paste a GitHub issue's link. Copilot becomes your teacher: what the project does, the task, where to look, what to change and how to prove it, then the fix, and explaining it in your own words.

The **opensrcer map** tab opens beside your editor: clusters of the project's code, blue where you chose to start, yellow where the fix changed it.

Reopen it any time from the status bar (**opensrcer**) or the Command Palette: *opensrcer: Show the code map*.
